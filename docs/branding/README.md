# baseSteam Artwork

![baseSteam logo](basesteam-logo.png)

`basesteam-logo.png` is the 1,254 by 1,254 pixel PNG prepared for the baseSteam CurseForge listing. Use the PNG itself as the project avatar. It retains the image generator's native resolution; the file has not been rescaled or retouched.

The copper BASE lettering, off-white STEAM lettering, charcoal metal background and steel/copper fittings match the established [basePower logo](https://github.com/MinecraftModDevelopmentMods/basePower/blob/master-1.10.2/docs/branding/basepower-logo.png), which follows the Base Metals visual family. The pressure gauge, brass valve and small steam outlet distinguish this expansion from basePower's shared machinery.

This artwork lives outside `src/main/resources` and does not change the qualified mod jars or their checksums. Preparing artwork and project text does not create a CurseForge project or publish a release. The paste-ready page description is in [curseforge-description.md](../curseforge-description.md).

## Creation

Created on 3 November 2026 with the built-in image-generation tool, using the existing basePower logo as the visual reference. The original generated image is retained locally; the project PNG is a byte-for-byte copy.

The brief was to preserve the established chunky pixel-art wordmark and metalwork, change POWER to STEAM, and replace the sprocket/coupling details with a pressure gauge and brass handwheel. The logo should remain readable as a project icon without captions, surrounding mockups or photographic effects.
